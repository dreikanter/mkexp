# Changelog

## [0.1.0] - 2026-03-28

### Added

- `mkexp new [--readme] [--git] [text...]` creates a date-prefixed experiment directory and prints its path
- `mkexp init` prints a shell integration snippet enabling the `mkx` shell function
- `MKEXP_PATH` env var to configure base directory (defaults to current directory)
- Random adjective-noun name generation when no text is provided
